# TinyCausalLM 模型说明

实现文件：[torch_demo.py](../src/llm_sde/torch_demo.py)。

## 这是什么模型

从随机初始化开始训练的 CPU 因果语言模型，用于验证日志采集、反向传播、真实参数更新与监控接口；不是下载或微调已有预训练大模型。

默认结构为词表 32、宽度 48、4 个注意力头、2 个 block、长度 24 的上下文、FFN 宽度 96、GELU、dropout=0、pre-norm、最后一层归一化及独立输出投影。每层自注意力都显式应用因果 mask；默认参数总数为 42,240。

## 数据与目标

默认数据为按词表取模的固定递增 token 序列，训练与验证使用分离 RNG。目标是 next-token 交叉熵，优化器为 AdamW，默认 batch size 为 12、学习率 0.002、裁剪范数 1、320 个 optimizer step。

提供 `--corpus` 时，改为本地文本的字符级训练。前 80% 与后 20% 分别用于训练/验证，字符表从整个输入语料构建。它不是外部预训练分词器；这种字符级验证也不能作为严格未见词表的泛化证据。

## 采集与产物

记录 Loss、裁剪前梯度范数、学习率、更新前参数范数、实测参数差范数；输出 CSV、JSONL、监控分数、配置、事件标签、训练摘要和 `state_dict` 检查点。

GitHub 整理包不分发检查点；运行训练命令会在本地产生，`.gitignore` 默认忽略它们。完整参数复制的测量方法仅供小模型验证，不是面向大模型的低开销探针。

## 不包含

不包含 GRPO/PPO、RLHF、奖励模型训练、LoRA、GPU/分布式训练或模型服务接口。主监控可以读取符合 schema 的其他训练日志，但该能力不意味着上述功能已完成。
