# Legacy: 01_baseline_sde（早期尝试，已归档）

这里保留的是项目最初"用 SDE 直接代理训练动力学"的数学原型，**不是当前主线代码**。
下面三段说明它当初在做什么、为什么不算数、后来被什么取代。

## 1. 当初在做什么

把训练当成一个粒子在势场里的随机运动，用随机微分方程（SDE）做数值演示：

- `double_well.py`：双井势 `U(x) = 1/4 x^4 - 1/2 x^2` 上的一维过阻尼朗之万采样，
  用 Euler–Maruyama 离散 `x <- x - U'(x)·dt + sigma·sqrt(dt)·dw`，`U'(x) = x^3 - x`。
- `langevin_llm.py`：把 SGD 的连续近似 `d(theta) = -grad L(theta) dt + sigma dW`
  套在同一个四次势上，用 `lr` 缩放漂移项，把"参数"当成标量粒子。
- `ou_process.py`：空文件（早期占位，从未实现）。
- `visualize.py`：跑 5000 步双井轨迹，打印最小值/最大值并画图。

## 2. 为什么这条路不算数

- **只有数值演示，没有真实训练**：输入全是随机数，不是任何 LLM 的 `loss` / `grad_norm` 序列，
  没有任何一步来自真实反向传播。
- **没有事件标签**：无法回答"这次异常提前了多少步"——连"异常"的定义都没有。
- **不可评估**：没有留出集，也没有提前召回、提前精确率这类指标，无法与任何基线比较。
- **维度与语义错配**：`theta` 是一个标量粒子，真实 LLM 参数是 10^6–10^9 维张量；
  损失面不是四次多项式，梯度噪声也不是各向同性高斯增量。
  作为"数学直觉"可以，作为"预测工具"不成立。

## 3. 后来被什么取代

- `src/llm_sde/synthetic.py`：可控注入的 telemetry 生成器
  （`loss` / `grad_norm` / `lr` / `update_norm` / `param_norm`），带明确事件标签与无害相似片段，
  作为事件级评估的数据底座。
- `src/llm_sde/torch_demo.py`：42,240 参数的 TinyCausalLM 真实训练循环，
  采真实 telemetry（`grad_norm` 由实际反向传播得到）。
- `src/llm_sde/monitor.py` + `src/llm_sde/features.py`：流式、有限内存、可解释的启发式监控与打分，
  按事件窗口（提前窗 / 事后窗）评估，而不是看曲线好不好看。

一句话：SDE 在这里只充当过"数学直觉"，可验证的部分换成了
**真实小模型 telemetry + 事件级监控评估**。
